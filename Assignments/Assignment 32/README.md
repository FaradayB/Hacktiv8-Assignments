Saya memilih dokumen-dokumen ini seperti pada tugas sebelumnya, saya suka dengan game ini, dan memiliki cerita yang kompleks dan panjang. Banyak sekali informasi mengenai plot dari game nya, gameplay, dan development an release game ini. Tentu saja informasi yang digunakan adalah bagian plot karena memiliki penjelasan yang cukup detil mengenai cerita dari game ini.

Bonus challenge yang saya lakukan adalah Multi-Turn memory, Source Citation, dan LLM as Judge.

Hasil dari source citation cukup baik karena sebelumnya saya juga memberikan citation juga tetapi tanpa pagenya karena tidak diperlukan, tetapi tetap saja hasilnya cukup memuaskan. Selain itu, hasil dari Multi-Turn Memory juga memberikan hasil jawaban yang sangat natural seperti berbicara dengan orang yang telah memainkan game ini juga.

Selain itu LLM as Judge juga berperan sangat baik dalam menjawab sesuai konteks. Terdapat pertanyaan seperti "What is the name of Rean's signature sword style?" yang jawabannya seharusnya adalah "Eight Leaves One Blades sword style" tetapi di salahkan karena memang tidak ada di konteks. Jadi model dapat mempelajari konteks cukup baik dan tidak mengalami halusinasi.
